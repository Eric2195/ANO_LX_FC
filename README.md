# ANO_LX_FC · 凌霄飞控源码

> 基于 **STM32F407** + 匿名科创（ANO）「凌霄」飞控框架的多旋翼飞控源码，采用裸机时分任务调度，支持姿态自稳 / 定高 / 定点 / 程控多种飞行模式，集成 IMU、GPS（u-blox M8）、光流等传感器与失控返航保护。

本仓库是在 **匿名科创 ANO 凌霄飞控** 框架基础上的工程整理与适配，主控为 STM32F407。代码采用裸机 + 时分调度器架构，集成了姿态解算、遥控器解析、GPS 定位、光流定位、失控保护与一键返航等完整飞控功能。

## ✨ 功能特性

- 🚁 **多种飞行模式**
  - 模式 1：姿态自稳 + 气压定高
  - 模式 2：自稳 + 定高 + 光流定点
  - 模式 3：程控（摇杆不参与，响应外部指令）
- 🧮 **姿态与位置控制**：基于 ANO 坐标系的角度 / 角速度 / 速度多级闭环。
- 📡 **传感器融合**：IMU（陀螺/加速度计）、磁力计、气压计、u-blox M8 GPS、匿名光流。
- 🎮 **遥控器解析**：支持 SBUS/PPM 等多种接收机协议，含死区与摇杆量转换。
- 🛡️ **失控保护**：遥控信号丢失 → 自动切换程控模式 → 一键返航（不可返航时自动降落）。
- ⚡ **电调输出**：8 路 PWM 输出（400 Hz），含 ESC 校准功能。
- 🔋 **电池监测**：ADC 实时采集电池电压。

## 🚀 快速开始

### 硬件平台

| 项目 | 参数 |
|------|------|
| 主控 | STM32F407（对应 `ProjectSTM32F407` 工程） |
| PWM 频率 | 400 Hz |
| 系统节拍 | 1000 Hz（1 ms） |
| GPS | u-blox M8（已在 `SysConfig.h` 中选型 `GPS_USE_UBLOX_M8`） |

### 编译烧录

1. 使用 **Keil MDK 5** 打开 `ProjectSTM32F407/` 下的 `.uvprojx` 工程文件。
2. 根据实际硬件确认 `FcSrc/SysConfig.h` 中的配置（GPS 选型、版本号等）。
3. 编译，通过 ST-Link / J-Link 下载至飞控。

### 飞行模式切换

通过遥控器 **CH5（AUX1）** 通道值切换：

| CH5 通道值 | 模式 | 说明 |
|-----------|------|------|
| < 1200 | 模式 1 | 姿态自稳 + 气压定高 |
| 1200 ~ 1700 | 模式 2 | 自稳 + 定高 + 光流定点 |
| ≥ 1700 | 模式 3 | 程控（响应外部指令） |

> 💡 在 2 秒内连续切换到程控模式 **3 次**，可触发**一键返航**。

## 🛠️ 技术栈

- **MCU**：STM32F407（ARM Cortex-M4）
- **库**：标准外设库 + 匿名科创凌霄飞控框架
- **IDE**：Keil MDK 5
- **架构**：裸机 + 时分任务调度器（`Ano_Scheduler`）
- **通信**：匿名上位机协议（`ANO_DT_LX`），可用于参数调试与波形观测
